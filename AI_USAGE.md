# AI Usage

OpenAI Codex was used as a learning and review assistant throughout this project. A local `AGENTS.md` file required it to explain concepts, provide only small next steps, and inspect the existing implementation before offering guidance.

Codex was explicitly prohibited from supplying complete features, making application code changes, or providing complete implementations. I remained responsible for writing, understanding, and testing the application code myself.

Codex was also used to review the finished project and help draft or update documentation for submission. All suggestions and documentation changes were reviewed before being included.
